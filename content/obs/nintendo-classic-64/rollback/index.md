『NINTENDO 64 Nintendo Classics』でゲーム内セーブを行ったあと、<br>
ソフトがエラー終了すると **セーブ前の状態まで進行状況が戻る** ことがあります

このページでは、この動作を便宜上「ロールバック現象」と呼びます<br>
Switch 2版の「巻き戻し」機能とは別の現象です

{{< callout type="warning" >}}
  ゲーム内でセーブ画面が表示されても、Nintendo Classics側のセーブデータへ<br>
  すぐに書き込まれているとは限りません
{{< /callout >}}

## 先に結論と対策

ゲーム内でセーブしたあと、**Nintendo Classicsを通常どおり終了** してください

## 被害を減らすポイント

- ゲーム内セーブだけで終わらせず、定期的にNintendo Classicsを終了する
- 長時間スリープしたままプレイを継続しない
- 大きなイベントの前後では「どこでもセーブ」も作成する
- 終了後に「セーブデータお預かり」のバックアップ状況を確認する
- 本体とNintendo Classicsを最新バージョンへ更新する

{{< callout type="warning" >}}
  クラッシュ後に古いデータが読み込まれた場合、同じデータへ新しくセーブすると、<br>
  失われた進行状況を復旧できる可能性がさらに低くなります<br>
  先に「どこでもセーブ」やクラウド上のバックアップを確認してください
{{< /callout >}}

## セーブ方法の違い

| 方法 | 注意点 |
| --- | --- |
| ゲーム本来のセーブ | クラッシュすると、ゲーム起動時の状態にもどることがある |
| どこでもセーブ | 1タイトルにつき最大4個です<br>破損することもあるため、完全に安心ではありません |

## ロールバックが起きる流れ

実際に起きた人の報告をもとに処理の流れをまとめたものです<br>
対策や解決に直接関係はないため、知りたい人だけご覧ください

{{< callout type="warning" >}}
  以下はRedditなどでの報告をもとに、挙動から予想したイメージ図です<br>
  内部実装が公式に公開されているわけではないため、厳密な仕様図ではありません
{{< /callout >}}

### ゲーム内でセーブした直後

ゲーム内でセーブすると、プレイ中の仮保存データは更新されます<br>
この時点では、本体側にあるNintendo Classicsのセーブデータがまだ更新されていない場合があります

{{< mermaid-file "00_save.mmd" >}}

### 正常に終了した場合

Nintendo Classicsを正常に終了すると、プレイ中の仮保存データが本体のセーブデータへ反映されます<br>
次回起動時にも、ゲーム内で保存した状態から再開できます

{{< mermaid-file "01_success.mmd" >}}

### クラッシュした場合

本体のセーブデータへ反映される前にクラッシュすると、プレイ中の仮保存データが失われます<br>
次回起動時には、最後に正常終了した時点など、以前のデータへ戻ったように見えます

{{< mermaid-file "02_rollback.mmd" >}}

## 公式情報

- [NINTENDO 64 Nintendo Classics｜任天堂サポート](https://support.nintendo.com/jp/nso/expansion/n64/index.html)
- [セーブデータをバックアップして別の本体で使用する｜Nintendo Switch 2 サポート](https://support.nintendo.com/jp/switch2/mastery/data/backup/index.html)

公式サポートでは、Nintendo Classicsのセーブデータが本体保存メモリーに保存されることと、<br>
「どこでもセーブ」を1タイトルにつき最大4個作成できることが案内されています<br>
一方、クラッシュ時の内部的な保存タイミングについては明記されていません
