## ゲーム画面を映す

Windowsでゲームをキャプチャする方法は大まかに2種類あります
1. ゲームキャプチャ
1. ウィンドウキャプチャ

![キャプチャ方法](capture-type.png)

## ゲームキャプチャ

![ゲームキャプチャの設定](game-capture.png)

| 項目 | 設定 |
| --- | --- |
| モード | 特定のウィンドウをキャプチャ<br>古いゲームなどは「フルスクリーンアプリケーション」を選択する方がいいこともあります |
| ウィンドウ | キャプチャしたいゲーム |
| ウィンドウの一致優先順位 | タイトルに一致、そうでなければ同じ実行可能ファイルのウィンドウを見つける |
| 音声をキャプチャ (ベータ版) | 後述 |
| キャプチャのフレームレートを制限する | 「ゲームは180FPSで動いてるけど、配信は60FPSで行いたい」などの場合に<br>OBSの負荷を下げることができるかもしれません<br>不安定になることもあり得ます |
| カーソルをキャプチャする | マウスカーソルを移すかの設定です。ゲームの性質やお好みで |
| サードパーティ製のオーバーレイをキャプチャする | オフ推奨 |

## 映らない場合

大抵はゲームキャプチャで問題ありません<br>
ただし、一部のゲームでは真っ黒になってしまい、キャプチャすることができません<br>
その場合は以下の対策を試してください

---
### 対策1 - OBSを管理者権限で起動する

![管理者として実行](run-as-administrator.png)

ゲームによっては管理者として実行することでキャプチャできるものがあります<br>
ゲームキャプチャのままキャプチャできることがメリットですが<br>
管理者権限で起動しないといけないため、以下のようなデメリットがあります
- 管理者権限で起動する手間
- セキュリティ面で管理者権限であること<br>
プラグインなどでセキュリティ的に問題があった際、トラブルの原因となりうる

---
### 対策2 - ウィンドウキャプチャでキャプチャする

ウィンドウキャプチャでなら、大抵のゲームはキャプチャできると思います<br>
デメリットとして、この方式ではフレームレートがゲーム画面そのままではなく、カクついて見えることがあります

![ウィンドウキャプチャの設定](window-capture.png)

| 項目 | 設定 |
| --- | --- |
| ウィンドウ | キャプチャしたいゲーム |
| キャプチャ方法 | Windows 10 (1903以降) |
| ウィンドウの一致優先順位 | タイトルに一致、そうでなければ同じ実行可能ファイルのウィンドウを見つける |
| 音声をキャプチャ (ベータ版) | 後述 |
| カーソルをキャプチャする | マウスカーソルを移すかの設定です。ゲームの性質やお好みで |
| クライアント領域 | チェック推奨<br>ウィンドウタイトルの枠を除外する設定です |
