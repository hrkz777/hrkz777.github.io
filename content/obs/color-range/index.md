ゲーム機の映像をOBSで取り込む場合、複数設定する場所があります

- ゲーム機の映像やディスプレイ (画面) 設定
- キャプチャーデバイス
- OBSの設定

それぞれを同じ設定に統一することが重要です<br>
設定が食い違うと、映像の色が全体的に濃くなったり、逆に全体的に白っぽくなる問題が発生します

{{< callout type="info" >}}
  HDRは色変換の扱いが難しいため、今回はHDR OFFを前提とします
{{< /callout >}}

## 基本設定

OBS側の色空間を `Rec. 709` に設定します<br>
カラーレンジ (色範囲 / RGBレンジ など) は<br>
問題が起きにくいため、リミテッドで統一するのがおすすめです<br>

{{< callout type="warning" >}}
  間違った設定を行うと **色が濃くなる / 薄くなる** といった問題が発生します<br>
  そのため、リミテッドで統一するのが最も手軽な設定となります
{{< /callout >}}

## キャプチャ設定

![キャプチャ設定](obs-input-color.png)

| 項目 | 設定の目安 |
| --- | --- |
| 色空間 | `Rec. 709` |
| 色範囲 | 下記表を参照 |
| HDR | OFF |

キャプチャーデバイスのフォーマットにより、うまく扱えるカラーレンジが決まります<br>
安全策はリミテッド (限定) です

| OBSで選択されている形式 | ゲーム機側の推奨 |
| --- | --- |
| NV12 | リミテッド |
| YUY2 | リミテッド |
| I420 | リミテッド |
| XRGB | フルも使用可能 |
| RGB・BGRA・BGRX | フルも使用可能 |
| MJPEG | キャプチャーカード依存のためリミテッドが安全 |

## 変更方法

### Switch2
設定 → ディスプレイ

| 項目 | 設定の目安 |
| --- | --- |
| RGBレンジ | OBS・キャプチャデバイスの色範囲と合わせる |
| HDR | OFF |
