## Switch / OBS の色設定

まずは色空間とレンジをそろえて、配信や録画で色が破綻しない状態を作ります。

### 色空間

OBS 側は `Rec.709` を基準にしておくと扱いやすいです。ゲーム機と編集・配信環境の前提を合わせやすくなります。

### RGB レンジ

Switch の RGB レンジと OBS の色範囲は、フルかリミテッドかを必ず統一します。食い違うと黒つぶれや白浮きが出ます。

### HDR

モニターや視聴環境ごとの差が大きく調整が難しいため、通常の録画・配信なら HDR 出力は OFF のままが無難です。

{{< note title="注意" >}}
フルレンジとリミテッドレンジを混在させると、意図せず色が濃くなったり、全体が灰色っぽく見えたりします。問題が出たら、ゲーム機、キャプチャデバイス、OBS の三点をまとめて見直すのが早いです。
{{< /note >}}

## PSP の取り込み方

PSP の外部出力は一般的な 16:9 ではないので、そのまま拡大せず、黒枠処理と比率調整を分けて考えます。

{{< figure-grid >}}
{{< article-figure src="psp-output-layout.png" alt="PSP の外部画面出力で 720x480 の中に 480x272 のゲーム画面が入る構成図" caption="PSP のゲーム画面は 720x480 の信号内に 480x272 相当で収まります。余白込みで出てくるため、最初から画面全体を拡大すると黒枠まで一緒に伸びます。" >}}
{{< article-figure src="psp-capture-settings.png" alt="OBS で PSP の黒枠をクロップし、スケーリングとアスペクト比で調整する例" caption="OBS では先にクロップ・パッドで黒枠を削り、その後にスケーリング・アスペクト比で表示サイズを整えます。" >}}
{{< /figure-grid >}}

1. **黒枠を削る**  
   プレビューで黒枠が見えなくなるまでクロップします。画像中の数値は参考値として使い、実機差があれば微調整します。
2. **サイズを合わせる**  
   黒枠を消したら、16:9 もしくは 480x270 を目安にスケーリングします。厳密には PSP の 480x272 は完全な 16:9 ではありません。
3. **必要なら色補正**  
   フルレンジで取り込んで色が強く出る場合のみ補正を追加します。リミテッド運用なら不要なことが多いです。

{{< note title="補足" >}}
PSP は通常の HDMI ソースのようにそのまま整う映像ではありません。まず見た目の余白を消し、そのあとで配信用の見せ方に合わせて比率を調整する方が破綻しにくいです。
{{< /note >}}
